# Tablou de bord cu surse multiple

Rulați `npm install`, apoi `npm start` și deschideți URL-ul afișat împreună cu instrumentele Network ale browserului. Rulați `npm test` pentru verificările automate.

Rulați `npm run test:browser` cu Chrome/Chromium disponibil pentru a valida frontiera reală HTTP, de module și DOM. Setați `CHROME_BIN` dacă executabilul nu se numește `google-chrome`.
